# Работа с проектом

1. Используйте Node.js 24 и `npm ci`.
2. Запустите `npm run dev`. Для обычной разработки интерфейса Rust не нужен.
3. Проверьте изменение через `npm test`, `npm run build` и `npm run format:check`.
4. Добавляйте тесты для новой бизнес-логики, ошибок хранения и важных пользовательских сценариев.

UI — на русском. Не добавляйте сетевые зависимости в обычную работу приложения, аналитику или реальные данные учителя в репозиторий. Демонстрационные данные должны быть явно подписаны.

Чистую логику размещайте вне компонентов React. Вызовы Windows проходят через `desktop.ts`; браузерный предпросмотр должен оставаться работоспособным. При изменении формата данных сохраняйте совместимость или добавляйте миграцию и тесты.

Основной формат поставки — установщик NSIS (`npm run installer`), дополнительно — переносной `.exe` (`npm run portable`). Для нативной сборки нужны Rust stable MSVC и Visual Studio C++ Build Tools. Не отмечайте нативные функции проверенными только на основании тестов с подменённым API.

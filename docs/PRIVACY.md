# Политика конфиденциальности

Приложение «Помощник учителя» (Teacher Companion) для Android и Windows.

Действует с 6 октября 2026 года.

## Коротко

Приложение **не собирает, не передаёт и не продаёт** персональные данные. Расписание, заметки и настройки хранятся только на вашем устройстве. Аккаунт и регистрация не нужны. Рекламы и сторонних счётчиков (аналитики) нет.

## Какие данные есть в приложении и где они хранятся

- **Расписание:** классы, предметы, кабинеты, звонки, каникулы, заметки к урокам, настройки. Хранятся только в памяти устройства: на Android — в данных приложения, на Windows — в папке `%APPDATA%\ru.teacher-companion.desktop`.
- **Резервные копии и QR-код** создаются только по вашей команде. Файл копии сохраняется туда, куда вы укажете; QR-код показывается на экране компьютера и считывается камерой телефона напрямую, без интернета и без серверов.
- Разработчик не видит и не получает ваше расписание и заметки.

## Обращения в интернет

- **Android:** приложение само в интернет не обращается. При первом сканировании QR-кода сервисы Google на телефоне могут один раз загрузить модуль распознавания — это делает система Android, приложение ничего не отправляет.
- **Windows:** раз в несколько часов приложение запрашивает с GitHub файл `latest.json`, чтобы узнать, вышла ли новая версия. Расписание при этом не отправляется. Проверку можно выключить: настройки → «Внешний вид» → «Проверять обновления».

## Разрешения на Android

| Разрешение                           | Зачем                                                                                                              |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| Уведомления                          | Текущий урок в шторке, напоминания перед уроком и перед звонком, утренняя и вечерняя сводки                        |
| Точные будильники                    | Чтобы напоминание «через 5 минут урок» пришло вовремя, а не с опозданием                                           |
| Запуск после перезагрузки            | Заново поставить напоминания после включения телефона или смены времени                                            |
| Работа в фоне (без экономии батареи) | Только по вашему нажатию: на некоторых телефонах иначе напоминания опаздывают                                      |
| Камера                               | Только для сканирования QR-кода при переносе расписания с компьютера; снимки не сохраняются и никуда не передаются |

## Удаление данных

Удалите приложение — вместе с ним удалятся расписание, заметки и настройки. На Windows данные остаются в папке, указанной выше, чтобы переустановка их не стёрла; удалите эту папку, если они больше не нужны. Резервные копии, которые вы сохранили сами, удаляются вручную.

## Дети

Приложение предназначено для учителей и не рассчитано на детей.

## Изменения

Если приложение начнёт обрабатывать какие-либо данные (например, при появлении оплаты платных функций), эта политика будет заранее обновлена, а изменения описаны в [истории изменений](../CHANGELOG.md).

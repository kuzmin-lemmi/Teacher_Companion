# Архитектура

| Модуль                            | Ответственность                                                   |
| --------------------------------- | ----------------------------------------------------------------- |
| `Shell.tsx`                       | Загрузка, навигация, первый запуск, сохранение, защита черновиков |
| `App.tsx`                         | Редакторы недельного расписания и звонков                         |
| `Widget.tsx`                      | Отображение дня, уроков и окон                                    |
| `Preferences.tsx` / `Backups.tsx` | Настройки и резервные копии                                       |
| `domain.ts` / `calendar.ts`       | Типы, валидация, поиск дня, календарные расчёты                   |
| `storage.ts` / `schema.sql`       | SQLite и отдельное хранилище браузерного предпросмотра            |
| `desktop.ts` / `geometry.ts`      | Адаптер Tauri и безопасные координаты окна                        |
| `hooks.ts`                        | Смена даты и системной темы                                       |
| `src-tauri/src/main.rs`           | Плагины Tauri, трей, единственный экземпляр, завершение           |

## Хранение

SQLite содержит таблицу `app_state` с одной строкой. `payload` — JSON-документ версии 1: `lessons`, `bells`, `settings`, `onboardingComplete`. Весь небольшой недельный набор сохраняется одной командой UPSERT. Проверка формата выполняется при чтении и перед записью.

Миграция SQLite и версия JSON независимы. Будущие задачи и исключения по датам могут получить отдельные таблицы. Текущий подход сохраняет атомарность без транзакции из нескольких вызовов через пул соединений.

В Windows SQL-плагин хранит `teacher-companion.db` относительно каталога конфигурации приложения (`ru.teacher-companion.desktop`). Положение виджета сохраняется отдельно в localStorage WebView: физические координаты учитывают мониторы слева от основного. При возврате к виджету положение ограничивается рабочей областью доступного монитора.

Браузер использует ключ `teacher-companion-preview-v1`. Это самостоятельный предпросмотр, а не доступ к desktop-базе.

## Правила

- Учебные дни: понедельник–пятница, с уроками. Поиск ограничен семью днями и начинается со следующей даты.
- Номера уроков: целые 1–20, уникальные в пределах дня. Класс обязателен.
- Общее время задаётся звонками, индивидуальное — переопределяет его.
- Уроки без времени разрешены. Известные интервалы не пересекаются и следуют порядку номеров.
- Окна — только внутренние пропущенные номера.
- Даты рассчитываются в локальной временной зоне. Таймер ставится до следующей полуночи; фокус и возвращение страницы также обновляют дату.
- Старые данные этапов 1–3 без `onboardingComplete` и с уроками открываются сразу в виджете.

## Windows

Одно окно меняет размер и оформление между виджетом и настройками. Виджет без рамки, с прозрачным фоном и без кнопки на панели задач; настройки имеют обычную рамку. Закрепление запрещает начало перетаскивания через шапку. Полупрозрачность применяется к фону, текст остаётся читаемым.

Трей создаётся в Rust и отправляет действия фронтенду. Закрытие в трей сохраняет открытый черновик. Полное завершение и переход со страницы с изменениями требуют решения пользователя. Single-instance-плагин поднимает уже открытое приложение вместо второго процесса.

Настройка автозапуска применяется перед сохранением. При ошибке записи выполняется попытка вернуть предыдущее значение. Ошибки показываются пользователю, а не маскируются сообщением об успехе.

## Резервные копии

Контейнер JSON: `application`, `backupVersion`, `createdAt`, `data`. Лимит 1 МБ. Проверяются версия, поля, размеры, время и пересечения. Восстановление возможно только после предпросмотра и подтверждения. Локальный автозапуск сохраняется; координаты чужого компьютера не импортируются.

Windows использует диалоги выбора файлов и ограниченный набор файловых команд. Произвольный глобальный доступ к файловой системе не запрашивается: пути разрешаются диалогом. Браузер использует загрузку файла и скачивание Blob.

Если SQLite физически повреждена и не открывается, восстановление через этот же файл может быть недоступно. Приложение сообщает ошибку и не удаляет исходную базу автоматически.

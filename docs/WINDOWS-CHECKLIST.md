# Проверка Windows перед выпуском

Статус: **ещё не выполнена**. Rust и C++ Build Tools на рабочем компьютере не устанавливались. Этот список — план приёмки, а не отчёт об успешных тестах.

## Запуск и данные

- [ ] Windows 10 и Windows 11 с WebView2: `.exe` запускается из обычной пользовательской папки.
- [ ] SQLite создаётся без прав администратора; после перезапуска уроки и настройки сохраняются.
- [ ] Второй запуск поднимает единственный существующий экземпляр.
- [ ] Работа при отключённой сети, включая первый запуск и редакторы.
- [ ] Замена `.exe` новой версией сохраняет базу и настройки.

## Окно

- [ ] Первый виджет справа сверху в рабочей области, без перекрытия панели задач.
- [ ] Перетаскивание и сохранение позиции; закрепление запрещает случайное движение.
- [ ] Компактный / обычный размер, длинные строки, 20 уроков и прокрутка.
- [ ] Масштаб 100%, 125%, 150%, 200%; Full HD и 2K; разные DPI двух мониторов.
- [ ] Монитор слева от основного; отключение монитора и повторное открытие виджета.
- [ ] Возврат из настроек сохраняет позицию виджета; сброс позиции работает.
- [ ] Режим поверх окон включается и выключается; прозрачность 80–100% читаема.
- [ ] Смена системной темы применяется при режиме «Системная».

## Жизненный цикл

- [ ] Крестик скрывает в трей по умолчанию; трей возвращает окно.
- [ ] Все пункты трея открывают правильный экран и день.
- [ ] Полный выход завершает процесс; несохранённые изменения защищены.
- [ ] Автозапуск включается, выключается и работает после повторного входа в Windows.
- [ ] После переноса `.exe` выключение и повторное включение автозапуска обновляет путь.
- [ ] Дата меняется после полуночи, после сна и при возвращении к окну.

## Файлы и ошибки

- [ ] Экспорт и импорт через нативные диалоги: выбранный файл доступен, отмена ничего не меняет.
- [ ] Невалидная копия и копия больше 1 МБ отклоняются; текущие данные сохраняются.
- [ ] Восстановление не включает автозапуск из копии другого компьютера.
- [ ] Недоступная для записи база / файл экспорта дают понятное сообщение.
- [ ] Повреждённая SQLite не удаляется и не перезаписывается автоматически.

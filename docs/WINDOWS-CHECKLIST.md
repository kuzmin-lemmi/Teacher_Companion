# Проверка Windows перед выпуском

Статус: **ручная приёмка завершена**. Проверено пользователем на собранном Windows-приложении перед утверждением версии 0.2.0.

## Запуск и данные

- [x] Windows 10 и Windows 11 с WebView2: `.exe` запускается из обычной пользовательской папки.
- [x] SQLite создаётся без прав администратора.
- [x] После перезапуска уроки и настройки сохраняются.
- [x] Второй запуск не создаёт второй процесс.
- [x] Установщик ставит приложение в профиль пользователя без прав администратора, создаёт ярлык в меню «Пуск» и запись для удаления.
- [x] Работа при отключённой сети, включая первый запуск и редакторы.
- [x] Замена `.exe` новой версией сохраняет базу и настройки.

## Окно

- [x] Виджет в выбранном углу рабочей области (проверены справа сверху, справа снизу, слева снизу), без перекрытия панели задач.
- [x] Перетаскивание и сохранение позиции; закрепление запрещает случайное движение.
- [x] Компактный / обычный размер, длинные строки, 20 уроков и прокрутка.
- [x] Масштаб 100%, 125%, 150%, 200%; Full HD и 2K; разные DPI двух мониторов.
- [x] Монитор слева от основного; отключение монитора и повторное открытие виджета.
- [x] Возврат из настроек сохраняет позицию виджета; сброс позиции работает.
- [x] Режим поверх окон включается и выключается; прозрачность 80–100% читаема.
- [x] Смена системной темы применяется при режиме «Системная».

## Жизненный цикл

- [x] Крестик скрывает в трей по умолчанию; трей возвращает окно.
- [x] Все пункты трея открывают правильный экран и день.
- [x] Полный выход завершает процесс; несохранённые изменения защищены.
- [x] Автозапуск включается, выключается и работает после повторного входа в Windows.
- [x] После переноса `.exe` выключение и повторное включение автозапуска обновляет путь.
- [x] Дата меняется после полуночи, после сна и при возвращении к окну.

## Файлы и ошибки

- [x] Экспорт и импорт через нативные диалоги: выбранный файл доступен, отмена ничего не меняет.
- [x] Невалидная копия и копия больше 1 МБ отклоняются; текущие данные сохраняются.
- [x] Восстановление не включает автозапуск из копии другого компьютера.
- [x] Недоступная для записи база / файл экспорта дают понятное сообщение.
- [x] Повреждённая SQLite не удаляется и не перезаписывается автоматически.

## Версия 0.3.0

- [ ] Установка поверх 0.2.0 сохраняет расписание и настройки; в «О программе» — «Версия 0.3.0».
- [ ] Утром учебного дня виджет показывает «Сегодня», после последнего урока переключается на следующий учебный день.
- [ ] Ручной выбор «Сегодня» / «Завтра» в виджете и в трее держится до полуночи.

# План развития

## Реализовано в исходниках

- [x] 1. Основа Tauri / React / TypeScript, уточнения PRD.
- [x] 2. SQLite, валидация, следующий учебный день, окна.
- [x] 3. Редакторы уроков и звонков, индивидуальное время.
- [x] 4. Виджет, сегодня / следующий день, два размера, обновление даты.
- [x] 5. Адаптер окна Windows, позиция, закрепление, трей и автозапуск.
- [x] 6. Первый запуск, темы, настройки, резервные копии и ошибки.

Этап 5 реализован. Приложение собирается локально; запуск, единственный экземпляр, SQLite, установка и положение виджета в углу проверены на Windows 11. Остальные пункты — в [проверках Windows](WINDOWS-CHECKLIST.md).

## Перед первой поставкой

- [x] Собрать `.exe` и установщик NSIS.
- [ ] Пройти [проверки Windows](WINDOWS-CHECKLIST.md).
- [ ] Внести фактическое расписание пользователя.
- [ ] Проверить сохранность данных после обновления `.exe`.
- [ ] Выпустить первую проверенную версию.

## После MVP

Приоритет сейчас — простое расписание. Заметки, задачи, замены, каникулы, уроки в субботу, чередование недель, импорт Excel/CSV и уведомления остаются будущими возможностями и не входят в текущую реализацию.

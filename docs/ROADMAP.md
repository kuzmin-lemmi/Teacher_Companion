# План развития

## Реализовано в исходниках

- [x] 1. Основа Tauri / React / TypeScript, уточнения PRD.
- [x] 2. SQLite, валидация, следующий учебный день, окна.
- [x] 3. Редакторы уроков и звонков, индивидуальное время.
- [x] 4. Виджет, сегодня / следующий день, два размера, обновление даты.
- [x] 5. Адаптер окна Windows, позиция, закрепление, трей и автозапуск.
- [x] 6. Первый запуск, темы, настройки, резервные копии и ошибки (с 0.6.0 — без обязательного мастера).

Все функции MVP реализованы и прошли ручную приёмку. Результаты зафиксированы в [проверках Windows](WINDOWS-CHECKLIST.md).

## Перед первой поставкой

- [x] Собрать `.exe` и установщик NSIS.
- [x] Пройти [проверки Windows](WINDOWS-CHECKLIST.md).
- [x] Проверить приложение на фактическом расписании пользователя.
- [x] Проверить сохранность данных после обновления `.exe`.
- [x] Выпустить первую проверенную версию — **0.2.0**.

## Выпущено после MVP

- [x] **0.3.0** — автоматический выбор дня: сегодня до конца уроков, затем следующий учебный день.
- [x] **0.4.0** — расписание на всю неделю в виджете.
- [x] **0.5.0** — автосохранение, черновики, автоматические резервные копии, обновление из программы.
- [x] **0.5.1** — отсчёт до конца урока и до следующего урока.
- [x] **0.6.0** — без обязательного мастера: сразу виджет, восстановление копии с пустого виджета.
- [x] **0.7.0** — каникулы и праздники, сокращённые дни, заметки к урокам.
- [x] **0.8.0** — перенос на телефон по QR-коду, пробная версия для Android ([план](ANDROID.md)).

## После MVP

Приоритет сейчас — простое расписание. Задачи, замены и переносы уроков, уроки в субботу, чередование недель, импорт Excel/CSV и уведомления остаются будущими возможностями и не входят в текущую реализацию.

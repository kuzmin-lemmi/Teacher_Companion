Приложение выходит в RuStore **бесплатным**, от аккаунта **физического лица**. План платных функций — в [MONETIZATION.md](MONETIZATION.md); к публикации он ничего не добавляет, кроме одного правила: в описании не обещаем «бесплатно навсегда».

## Шаг 1. Аккаунт разработчика

1. Откройте [RuStore Консоль](https://console.rustore.ru/) → **«В консоль»** → **«Войти через VK ID»**.
2. Тип аккаунта — **«Физическое лицо»**.
3. Заполните контакты: телефон и почту для связи с RuStore. Если спросят сайт — `https://github.com/kuzmin-lemmi/Teacher_Companion`.
4. Пройдите проверку личности: фото паспорта и лицо в камеру.
5. Примите соглашение с разработчиком.

Создание аккаунта и публикация бесплатны. Позже аккаунт можно перевести в ИП через поддержку RuStore — приложение, отзывы и установки сохраняются.

## Шаг 2. Новое приложение

1. **«Приложения» → «Создать приложение»** → Android.
2. Загрузите `TeacherCompanion-Android.apk` последней версии со [страницы релизов](https://github.com/kuzmin-lemmi/Teacher_Companion/releases/latest).
3. Пакет определится сам: `ru.teachercompanion.app`. Его уже нельзя будет сменить — и не нужно.

## Шаг 3. Карточка приложения

**Название** (16 символов):

```text
Помощник учителя
```

Под значком на телефоне — то же название: RuStore требует, чтобы они совпадали.

**Краткое описание** (76 из 80 символов):

```text
Расписание уроков, звонки и напоминания для учителя — работает без интернета
```

**Полное описание:**

```text
«Помощник учителя» — ваше расписание уроков всегда под рукой: в приложении, в шторке, на экране блокировки и на рабочем столе.

Каждый день
• Уроки на сегодня: класс, предмет, кабинет и время. Идёт урок — видно, сколько до звонка; на перемене — сколько до следующего урока.
• После уроков приложение само показывает следующий учебный день.
• Вся неделя одной таблицей, «окна» между уроками видны сразу.
• Заметки к уроку на конкретную дату: «самостоятельная», «собрать тетради».

Звонки и календарь
• Расписание звонков заполняется в одно касание.
• Сокращённые дни со своими звонками.
• Каникулы и праздники: в эти дни уроков нет, а приложение показывает, когда учёба продолжится.

Напоминания
• Перед уроком: «Через 5 мин — 7Б · каб. 214» и заметка к уроку.
• Перед концом урока: «Через 5 мин звонок — пора подводить итоги и задавать ДЗ». Текст можно написать свой.
• Утренняя сводка: какой сегодня день, сколько уроков, какой первый и во сколько.
• Сводка на завтра вечером — с заметками к урокам.
• Для каждого напоминания — мягкий перезвон, только вибрация или беззвучно. Во время урока телефон не звенит, а только вибрирует.

На рабочем столе
• Виджет «Сейчас и далее»: текущий урок и отсчёт до звонка.
• Виджет «Уроки на день».
• Текущий урок в шторке и на экране блокировки.

С компьютера на телефон
Есть версия для Windows с виджетом расписания на рабочем столе. Расписание переносится на телефон по QR-коду — без интернета, без почты и облака.

Ваши данные — только у вас
• Без регистрации и аккаунта.
• Расписание хранится только на телефоне и никуда не отправляется. Приложение работает без интернета.
• Без рекламы.
```

**Категория:** Образование.

## Шаг 4. Чувствительные разрешения

RuStore просит объяснить каждое такое разрешение. Тексты:

| Разрешение                                | Обоснование                                                                                                                                                                                                                      |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `POST_NOTIFICATIONS`                      | Показывает текущий урок в шторке и напоминания из расписания пользователя: перед уроком, перед концом урока, утреннюю и вечернюю сводки. Каждое уведомление включается и выключается в настройках.                               |
| `USE_EXACT_ALARM`, `SCHEDULE_EXACT_ALARM` | Приложение — расписание уроков и звонков. Напоминание «через 5 минут урок» или «через 5 минут звонок» должно прийти в точное время, а не с опозданием. Будильник ставится только на ближайший момент из расписания пользователя. |
| `RECEIVE_BOOT_COMPLETED`                  | Заново поставить напоминания после перезагрузки телефона, обновления приложения и смены времени.                                                                                                                                 |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`    | Запрашивается только по нажатию пользователя «Разрешить работу в фоне» — на телефонах, где система откладывает напоминания ради экономии батареи.                                                                                |
| `CAMERA`                                  | Только для сканирования QR-кода при переносе расписания с компьютера. Снимки не сохраняются и никуда не передаются.                                                                                                              |

## Шаг 5. Модерация

1. **«Отправить на модерацию».** Обычно проверка занимает от нескольких часов до нескольких рабочих дней.
2. Если откажут — в консоли будет причина. Частые: недоступная политика конфиденциальности, необоснованные разрешения, расхождение описания и приложения, разные названия в магазине и под значком. Пришлите причину — поправим и отправим снова.
3. После одобрения приложение публикуется автоматически (или по кнопке, если выбрать публикацию вручную).

## После публикации

- **Ссылка на приложение в RuStore** — добавить в README рядом с «Скачать для Android».
- **Новая версия:** выпустить релиз на GitHub как обычно, затем в консоли **«Новая версия»** → загрузить тот же `TeacherCompanion-Android.apk` → «Что нового» из `docs/releases/vX.Y.Z.md`. Номер сборки растёт сам вместе с версией.
- **Установленные из RuStore** получают обновления через RuStore и не видят в приложении ссылок на GitHub. Установленные файлом с GitHub могут перейти на RuStore, поставив его поверх: пакет и подпись одни и те же, расписание сохранится.
- **Ключ подписи** (`ANDROID_KEYSTORE_BASE64`) — тот же для GitHub и RuStore. Потерять его — значит больше не выпустить ни одного обновления: храните копию отдельно от GitHub.

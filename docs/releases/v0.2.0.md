Первая версия, которую можно установить как обычную программу Windows: расписание ближайшего учебного дня всегда на рабочем столе.

<p align="center"><img src="https://raw.githubusercontent.com/kuzmin-lemmi/Teacher_Companion/v0.2.0/docs/images/widget-dark.png" width="360" alt="Виджет расписания"></p>

## Как установить

1. Скачайте **`TeacherCompanion-Setup.exe`** ниже, в разделе **Assets**.
2. Запустите. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите **«Подробнее» → «Выполнить в любом случае»** (у программы пока нет платного сертификата подписи).
3. Пройдите короткий мастер: звонки, уроки, внешний вид.

Права администратора не нужны, интернет — только для скачивания. Подробно: **[инструкция по установке и использованию](https://github.com/kuzmin-lemmi/Teacher_Companion/blob/main/docs/GUIDE.md)**.

`TeacherCompanion-Portable.exe` — вариант без установки. Для автозапуска держите его в постоянной папке.

## Что нового

- Установщик Windows: ярлык в меню «Пуск», удаление через «Установленные приложения».
- Новый дизайн виджета: одна строка на урок, окно подстраивается под расписание — весь день виден без прокрутки.
- Шрифт Inter, встроен в программу.
- Окно (свободный урок) показывается со временем звонка; одинаковые предмет и кабинет — один раз внизу.
- «Сегодня»: текущий урок выделен, прошедшие приглушены.
- Выбор угла экрана и компактный размер в настройках.
- Резервные копии версии 0.1 открываются без изменений.

## Проверено

Windows 11, 1920×1080, масштаб 100%: установка, обновление поверх, запуск, единственный экземпляр, база данных, положение виджета в углах. Трей, автозапуск, несколько мониторов и другие масштабы экрана ещё проходят [проверку](https://github.com/kuzmin-lemmi/Teacher_Companion/blob/main/docs/WINDOWS-CHECKLIST.md) — если заметите проблему, напишите в [Issues](https://github.com/kuzmin-lemmi/Teacher_Companion/issues).

Контрольные суммы файлов — в `SHA256SUMS.txt`.

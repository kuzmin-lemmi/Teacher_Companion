Помощник учителя 0.3.0: утром виджет показывает сегодняшние уроки, а после последнего урока — следующий учебный день.

## Как установить или обновить

1. Скачайте **`TeacherCompanion-Setup.exe`** ниже, в разделе **Assets**.
2. Запустите. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите **«Подробнее» → «Выполнить в любом случае»** (у программы пока нет платного сертификата подписи).
3. Если версия 0.2.0 уже установлена, новая встанет поверх неё. Расписание и настройки сохранятся.

Подробно: **[инструкция по установке и использованию](https://github.com/kuzmin-lemmi/Teacher_Companion/blob/main/docs/GUIDE.md)**.

`TeacherCompanion-Portable.exe` — вариант без установки. Для автозапуска держите его в постоянной папке.

## Что нового

- **Виджет сам выбирает день.** В учебный день он показывает сегодняшнее расписание, пока не закончился последний урок, а потом — следующий учебный день. Если звонки не заполнены, виджет, как и раньше, сразу показывает следующий день.
- **Ручной выбор держится до конца дня.** Нажали «Завтра» утром или выбрали день в трее — виджет покажет его до полуночи, а на следующий день снова будет выбирать сам.
- Версия программы теперь везде одна и берётся из одного места.
- Для разработчиков: проверки на GitHub включают Rust (`cargo fmt`, `cargo clippy`), код главного окна разделён на отдельные компоненты.

Резервные копии версий 0.1 и 0.2 открываются без изменений.

Если заметите проблему, напишите в [Issues](https://github.com/kuzmin-lemmi/Teacher_Companion/issues).

Контрольные суммы файлов — в `SHA256SUMS.txt`.

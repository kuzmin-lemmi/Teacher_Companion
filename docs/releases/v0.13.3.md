Помощник учителя 0.13.3: исправлена вёрстка настроек на Windows.

## Как установить или обновить

**Windows** — откройте «О программе» и нажмите **«Установить версию 0.13.3»**; расписание и настройки сохранятся. Первая установка — **`TeacherCompanion-Setup.exe`** ниже, в разделе **Assets**. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите **«Подробнее» → «Выполнить в любом случае»**.

**Android** — в этой версии есть подготовка к RuStore; всё остальное без изменений. Установите **`TeacherCompanion-Android.apk`** поверх прежней версии.

Подробно: **[инструкция для Windows](https://github.com/kuzmin-lemmi/Teacher_Companion/blob/main/docs/GUIDE.md)** · **[Android](https://github.com/kuzmin-lemmi/Teacher_Companion/blob/main/docs/ANDROID.md)**.

## Что нового

- **Windows:** в «Настройки → Внешний вид» пропала лишняя полоса прокрутки, а панель «Сохранить настройки» теперь тянется на всю ширину окна и не обрезается по бокам.
- **Android:** под значком теперь полное название «Помощник учителя»; приложение узнаёт, что установлено из RuStore, и тогда не предлагает скачивать обновления с GitHub.

Если заметите проблему, напишите в [Issues](https://github.com/kuzmin-lemmi/Teacher_Companion/issues).

Контрольные суммы файлов — в `SHA256SUMS.txt`.
